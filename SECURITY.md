# Security policy

PulseCord is a development preview and does not publish supported binaries yet.

Please do not open public issues for vulnerabilities that expose credentials, tokens, private messages, or remote-code-execution paths. Report them privately through GitHub's **Report a vulnerability** feature when it is enabled. Until then, contact the repository owner through their GitHub profile without including secrets in the first message.

Never send Discord passwords, session cookies, tokens, or full diagnostic archives. PulseCord will not ask for them.

The project does not promise a bug-bounty payment. Good-faith security research that avoids accessing other people's data is welcome.
