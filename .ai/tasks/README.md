# `.ai/tasks/`

Handoff de tarefas de IA isoladas em branches `ai/*`. Cada tarefa concluída
grava seu próprio `<identificador-unico>.md` aqui (agente, branch, objetivo,
mudanças, testes, pendências, commits) para o agente integrador consumir.

Não é changelog público nem estado oficial do projeto — isso é
`PROJECT_STATE.md`, atualizado só na integração. Ver `AI_RULES.md`.
